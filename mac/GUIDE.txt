AI Usage Bar for Mac — 사용 안내 / User guide
(한국어 먼저, English below)

==================== 한국어 ====================

AI Usage Bar 맥용 — 처음 사용하시는 분께

가장 먼저 할 일
1. ZIP을 풀고 Install.command 실행 → 앱 설치와 자동 실행 등록
2. Setup-Login.command 실행 → 공식 Codex/Claude Code CLI 설치와 계정 로그인
3. AI Usage Bar 창에서 새로고침 누르기
이미 CLI에 로그인되어 있으면 2번은 생략해도 됩니다.

어떤 맥에서 되나요?
macOS 13 이상 권장. Intel 맥과 Apple Silicon 맥에서 각 맥에 맞게 앱을 만듭니다.
인터넷과 Apple Command Line Tools가 필요합니다.
이 ZIP은 미리 빌드한 앱이 아니라 맥에서 앱을 만드는 소스/설치 패키지입니다.
Apple 도구가 없으면 설치 창이 나타납니다. 도구 설치 후 Install.command를 다시 실행하세요.
앱 설치에는 전체 Xcode가 필요하지 않습니다. Apple 도구 설치 시 macOS가 암호를 물을 수 있습니다.
앱 설치 위치: 내 사용자 폴더 > Applications > AI Usage Bar.app

로그인은 어떻게 하나요?
받는 분이 자신의 계정으로 각각 한 번 로그인합니다. AI Usage Bar 별도 가입은 없습니다.
ZIP에는 보낸 사람의 비밀번호, 로그인 파일, 토큰, 쿠키가 전혀 들어 있지 않습니다.

Codex:
  Setup-Login.command의 첫 단계 또는 앱의 'Codex 로그인' 버튼을 사용하세요.
  터미널에서 직접 하려면: codex login
  브라우저가 열리면 본인의 ChatGPT 계정으로 로그인하고 승인을 완료하세요.
  API 키 로그인 대신 ChatGPT 계정 로그인을 사용하세요.
  인증 저장/갱신은 Codex가 관리합니다.

Claude:
  Setup-Login.command의 두 번째 단계 또는 앱의 'Claude 로그인' 버튼을 사용하세요.
  터미널에서 직접 하려면: claude auth login
  브라우저에서 본인의 Claude 구독 계정으로 로그인하고 승인을 완료하세요.
  Claude Code에 접근 가능한 구독 계정이 필요합니다.
  API 키/Console 결제 계정의 사용 금액을 조회하는 용도가 아닙니다.
  맥에서는 Claude Code 로그인 정보가 보통 암호화된 키체인에 저장됩니다.
  AI Usage Bar가 키체인 접근을 요청하면 앱 이름을 확인하고 허용하세요.
  키체인 암호는 보통 맥 로그인 암호입니다.
  키체인 대신 파일에 저장된 기본 로그인도 지원합니다.

웹 브라우저나 ChatGPT/Claude 데스크톱 앱에만 로그인한 것과 CLI 로그인은 다를 수 있습니다.
로그인 완료 후 앱에서 새로고침을 누르세요.
매번 맥을 켤 때 다시 로그인하지 않아도 됩니다. 로그인이 만료/취소되면 재로그인하세요.

Windows 버전과 같은 원리인가요?
네. Codex는 codex app-server --stdio의 account/rateLimits/read에서
10080분(7일) 주간 한도를 찾고, Claude는 /api/oauth/usage의 seven_day를 읽습니다.
Claude 토큰이 만료되면 기존 앱처럼 OAuth 갱신 후 원래 저장소에 저장합니다.
다른 로그인을 덮어쓰지 않도록 저장 직전에 현재 인증을 다시 확인합니다.
Claude Code와 동시에 인증을 갱신하는 경우에는 재로그인이 필요할 수 있습니다.
2분마다 갱신하고, 요청 제한 응답에서는 Retry-After와 지수형 대기를 지킵니다.
임시 오류가 생기면 이전 사용량임을 표시합니다.
사용량 확인을 위해 AI에게 질문을 보내지 않습니다.
Codex 한도는 일반 ChatGPT 채팅 전체의 사용량과 같지 않습니다.
API 결제 금액을 보여 주는 앱도 아닙니다.

맥을 켜고 끌 때
설치하면 사용자 로그인 시 별도 창이 자동으로 열립니다.
전원을 끄면 종료되고, 다음 부팅 후 로그인하면 다시 열립니다.
잠자기에서 깨면 실행 중인 앱의 데이터를 새로고침합니다.
창을 닫으면 앱이 종료됩니다. 다시 보려면 AI Usage Bar.app을 여세요.
중복 실행은 기존 창을 앞으로 가져옵니다.
Disable-Autostart.command: 로그인 시 자동 실행 끄기
Enable-Autostart.command: 자동 실행 다시 켜기
macOS가 차단했다면 시스템 설정 > 일반 > 로그인 항목에서 확인하세요.

실행이 안 될 때
실행 권한이 없다는 오류가 나오면 터미널에 /bin/bash 를 입력하고 공백 한 칸을 둔 뒤,
실행하려는 .command 파일을 Finder에서 터미널로 끌어 놓고 Enter를 누르세요.
다운로드 보호 알림이 나오면 시스템 설정 > 개인정보 보호 및 보안에서
실행하려는 파일을 확인한 뒤 macOS가 제공하는 열기 절차를 따르세요.
CLI 설치 필요: Setup-Login.command를 실행한 뒤 앱을 다시 여세요.
연결 오류: 네트워크 확인 후 새로고침
요청 제한: 표시된 시간까지 기다리세요. 새로고침도 대기 시간을 지킵니다.
주간 데이터 없음: 서비스가 그 계정에 주간 사용량을 제공하는지 확인하세요.
각 서비스 로그인은 공유된 맥 사용자 계정의 CLI 로그인에도 영향을 줍니다.

검증 범위 및 제약
Apple Silicon 맥에서 빌드·설치·자동 실행 등록을 확인했습니다. Intel 맥은 아직 검증하지 못했습니다.
설치 시 사용량 응답 해석 자체 검사가 실행되고 실패하면 설치를 중단합니다.
현재 기본 Claude Code 키체인 항목(Claude Code-credentials)을 지원합니다.
별도 CLAUDE_CONFIG_DIR의 키체인 항목은 미지원입니다.
로그인 셸의 nvm 등 사용자별 PATH는 자동 탐색하지 않습니다.
기본 ~/.local/bin, ~/.npm-global/bin, /opt/homebrew/bin, /usr/local/bin 등을 찾습니다.
Claude 사용량 조회 주소는 공개적으로 보장된 정식 API가 아니므로 서비스 변경에 영향을 받습니다.

제거하기
Disable-Autostart.command를 실행하고 AI Usage Bar.app을 휴지통으로 옮기세요.
앱 제거는 CLI의 로그인을 지우지 않습니다.
공용 맥에서는 각각 codex logout / claude auth logout 으로 로그아웃하세요.

==================== English ====================

AI Usage Bar for Mac — getting started

First steps
1. Unzip and run Install.command → builds and installs the app, turns on autostart
2. Run Setup-Login.command → installs the official Codex CLI / Claude Code and signs in
3. Click Refresh in the AI Usage Bar window
If you are already signed in to both CLIs, skip step 2.
Tip: running the scripts from Terminal (bash path/to/Install.command) avoids the
macOS warning shown when double-clicking an unsigned .command file.

Which Macs?
macOS 12 or later (13+ recommended). The app is compiled on your Mac for its CPU,
so both Intel and Apple Silicon work. Needs internet and Apple Command Line Tools.
This ZIP contains source and install scripts, not a prebuilt app.
If the Apple tools are missing, an install window appears; run Install.command again afterwards.
Full Xcode is not needed. macOS may ask for your password while installing the tools.
App location: your home folder > Applications > AI Usage Bar.app

How do I sign in?
Everyone signs in once with their own accounts. There is no separate AI Usage Bar account.
The package contains no passwords, sign-in files, tokens or cookies from anyone else.

Codex:
  Use step 1 of Setup-Login.command or the app's "Codex Login" button.
  In Terminal: codex login
  Sign in with your own ChatGPT account in the browser (not an API key).
  Codex stores and renews the sign-in itself.

Claude:
  Use step 2 of Setup-Login.command or the app's "Claude Login" button.
  In Terminal: claude auth login
  Sign in with your own Claude subscription account that includes Claude Code.
  This does not show API / Console billing.
  On a Mac, the Claude Code sign-in is usually kept in the Keychain.
  If AI Usage Bar asks for Keychain access, check the app name and allow it
  (the Keychain password is usually your Mac login password).
  A file-based sign-in (~/.claude/.credentials.json) is also supported.

Being signed in to the ChatGPT/Claude website or desktop apps is not the same as the CLI sign-in.
After signing in, click Refresh. You do not need to sign in again after every restart.

How it works
Codex: reads account/rateLimits/read from `codex app-server --stdio` and picks the
10080-minute (7-day) weekly window. Claude: reads seven_day from /api/oauth/usage.
If the Claude token has expired, the app renews it and saves it back to where it came from,
re-checking the current sign-in first so it never overwrites a different login.
If Claude Code renews at the same moment, you may need to sign in again.
Refreshes every 2 minutes; on rate limits it honors Retry-After with exponential backoff.
On temporary errors it keeps showing the last values and marks them as old.
It never sends a prompt to any AI to check usage.
The Codex limit is not your overall ChatGPT chat usage, and this is not an API billing tool.

Starting and stopping
The window opens automatically when you log in to the Mac, and refreshes after waking from sleep.
Closing the window quits the app; open AI Usage Bar.app to show it again.
Opening it again while it runs brings the existing window to the front.
Disable-Autostart.command: turn off opening at login
Enable-Autostart.command: turn it back on
If macOS blocked it, check System Settings > General > Login Items.

Troubleshooting
"Permission denied": type /bin/bash and a space in Terminal, drag the .command file in, press Enter.
CLI not installed: run Setup-Login.command, then reopen the app.
Connection error: check the network, then Refresh.
Rate limited: wait until the time shown; Refresh also respects the wait.
No weekly data: check that the service provides a weekly limit for that account.
Sign-ins are per macOS user account and shared with the CLIs.

Tested / limitations
Built, installed and autostart-registered on an Apple Silicon Mac. Intel Macs not tested yet.
The installer runs a response-parsing self-test and stops if it fails.
Supports the default Claude Code Keychain item (Claude Code-credentials);
a separate CLAUDE_CONFIG_DIR Keychain item is not supported.
nvm-style per-user PATHs are not searched; looks in ~/.local/bin, ~/.npm-global/bin,
/opt/homebrew/bin, /usr/local/bin, etc.
The Claude usage address is not a documented public API and may change.

Uninstall
Run Disable-Autostart.command and move AI Usage Bar.app to the Trash.
This does not sign you out of the CLIs. On a shared Mac use codex logout / claude auth logout.
